Workload & Load Testing

Trigger CPU utilization spikes to validate autoscaling behavior
🔒
Architectural Security Notice: Client-Side Shell Isolation

In accordance with secure cloud architecture best practices, browser JavaScript has no shell access or direct privileged cluster connectivity. Load generation can only be commanded via an authenticated backend proxy or executed directly through the cluster CLI.

Method A: Terminal Load Generator (Recommended)

Launch a temporary busybox load generator pod inside the cluster that generates high-concurrency HTTP queries to the service:

kubectl run -i --tty load-generator --rm --image=busybox:1.28 --restart=Never -- /bin/sh -c "while sleep 0.01; do wget -q -O- http://gke-hpa-monitor-service; done"
1 Run the command above in a separate terminal window.
2 Watch the HPA scale up: kubectl get hpa gke-hpa-monitor-hpa --watch
3 Press Ctrl+C in the load-generator terminal to observe the cooldown scale-down.

Core Cloud & Kubernetes Concepts

Academic explanations of cluster management and auto-scaling mechanics
☁️

Google Kubernetes Engine (GKE)

GKE is a managed, production-ready environment for deploying containerized applications. It brings Google's latest innovations in developer productivity, resource efficiency, automated operations, and open source flexibility to accelerate time to market, handling control-plane provisioning, node upgrades, and health repair automatically.

📦

Kubernetes Pods

Pods are the smallest deployable units of computing that you can create and manage in Kubernetes. A Pod encapsulates one or more application containers, shared storage volumes, and network specifications (including unique IP addressing and port bindings).

⚡

Horizontal Pod Autoscaler (HPA)

HPA automatically scales the number of Pod replicas in a deployment based on observed metrics like CPU utilization or custom metrics. It queries the Metrics Server periodically and computes the required pod count using the formula: Desired = ceil[Current × (CurrentUtilization / TargetUtilization)].
